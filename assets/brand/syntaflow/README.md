# Syntaflow Brand Assets

This directory contains the official Syntaflow visual brand marks, application icons, and logo assets.

---

## Approved Brand Files

| File | Purpose | Dimensions / Format |
|---|---|---|
| `logo-icon.png` | Primary application icon mark (app switcher, taskbar, tray, compact navigation) | High-resolution PNG mark (1254x1254, transparent) |
| `logo-icon.ico` | Windows desktop application & taskbar icon | Multi-resolution ICO (16, 24, 32, 48, 64, 128, 256) |
| `logo-full.png` | Full horizontal logomark with Syntaflow wordmark | High-resolution PNG logo (3012x1004, transparent) |
| `logo-full-color.png` | Full horizontal logomark with colored gradient wordmark | High-resolution PNG logo (2172x724, transparent) |

---

## Brand Guidelines

1. **Brand Identity**: The product name is **Syntaflow** (PascalCase).
2. **Brand Essence**: *Intelligence in Flow* · *From context to action*.
3. **Usage Rules**:
   - Use `logo-icon.png` where space is compact or icon-oriented (sidebar collapsed, window chrome, compact headers, startup mark, app icon).
   - Use `logo-full.png` where horizontal space allows the full product name to be clearly legible (login/auth surfaces, expanded navigation, settings/about header).
   - Never stretch, redraw, or recolor the approved logos. Always preserve aspect ratio with `object-fit: contain`.
4. **Color System**:
   - Graphite: `#0A0D10`
   - Charcoal: `#11161B`
   - Paper: `#F4F6F8`
   - Cobalt: `#2F6BFF` / `#2F6FEB`
   - Cyan: `#2ED3FF` / `#25B7F3`
