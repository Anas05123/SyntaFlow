# CoreDesk Brand Assets

This directory contains the official CoreDesk visual brand marks, application icons, and logo assets.

---

## Brand Files

| File | Purpose | Dimensions / Format |
|---|---|---|
| `coredesk-icon.png` | Primary application icon mark (app switcher, taskbar, tray) | High-resolution PNG mark (1254x1254) |
| `coredesk-icon.ico` | Windows desktop application & taskbar icon | Multi-resolution ICO (16, 24, 32, 48, 64, 128, 256) |
| `coredesk-logo-full.png` | Full horizontal logomark with CoreDesk wordmark | High-resolution PNG logo |

---

## Brand Guidelines

1. **Brand Identity**: The product name is **CoreDesk** (one word, PascalCase). Never spell it as "Core Desk", "Coredesk", or use the retired name "Atlas".
2. **Color System**:
   - Primary Surface: Canvas `#0B0D0F` / Graphite `#12161A`
   - Primary Accent: Cobalt `#3B82F6` / Cyan `#06B6D4`
   - Crisp White Text: `#F8FAFC`
   - Muted Secondary: `#94A3B8`
3. **Geometry**: Rounded rect contours with smooth curvature.
4. **Tooling & Generation**:
   - Vector mark generators and render scripts are located in `tools/brand/` (`tools/brand/gen-mark.mjs`, `tools/brand/render-mark.mjs`).
