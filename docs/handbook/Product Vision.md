# Product Vision

AI Agency OS is a local-first desktop operating system for digital agencies.

It connects the complete workflow:

Discover businesses → analyze opportunities → prioritize leads → generate tailored websites → review and deploy → manage outreach → convert and manage clients.

## Core Value Proposition

From finding a business to delivering a live website—all inside one intelligent workspace.

## Target User

Version 1 is built primarily for the founder.

Future users include freelancers, web agencies, sales teams, and small digital-service companies.
