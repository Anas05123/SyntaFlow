# Project Atlas

> AI Agency OS - Engineering Handbook and single source of truth.

## Project Principles

- Offline-first.
- No mandatory subscription.
- Security before convenience.
- Maintainability and quality before development speed.
- Every feature must save time, make money, or improve quality.
- ChatGPT handles product planning and architecture.
- Codex implements approved specifications.
- Ollama provides local AI capabilities.
