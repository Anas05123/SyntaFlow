﻿# UI UX System

## Design Direction

- Professional desktop interface.
- Clean blue-and-white visual identity.
- Light and dark modes.
- Consistent component library.
- No unnecessary scrolling.
- Common actions reachable within two clicks.
- Background tasks must never freeze the interface.
- Every loading operation must show progress.

- Command Center
