# Archive Index

This folder stores historical Project Atlas material only.

Active documents never live here. Active specifications, decisions, architecture documents, Codex tasks, research notes, and standards must remain in their active folders.

Use this archive for documents that are:

- Replaced by newer versions
- Rejected after review
- Deprecated by architecture changes
- Preserved for historical context
- Superseded by an approved decision

## Project Principles Preserved

- Offline-first.
- No mandatory subscription.
- ChatGPT acts as CTO and planning partner.
- Codex implements approved specifications.
- Ollama is the default local AI runtime.
- AI Agency OS uses a modular monolith architecture.
- Security, maintainability, and documentation come before speed.
- Documentation-first workflow remains mandatory.

## Archive Rule

If a document is still used to guide current planning, architecture, design, implementation, or Codex work, it does not belong in this folder.
